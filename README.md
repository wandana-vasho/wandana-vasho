### The 10-second version

My most-recent capstone: a baseline model scored **0.994** — a number that
should have shipped as a win. Instead of reporting it, I audited *why* it
was that clean, found the baseline and the label were built from the same
formula, named the flaw, and published the honest result instead. That
habit — checking the number before trusting it — is the throughline across
everything below.

**What I'm looking for:** Backend / AI engineering roles where someone
questioning a number before it ships is a feature, not friction.
